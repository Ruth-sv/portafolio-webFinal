---

Portafolio web de diseño gráfico (especialidad multimedia). Página estática: `index.html`, `styles.css` y `script.js`, sin dependencias ni instalación.

## Cómo editar

- **Proyectos (textos, imágenes, videos, bitácoras):** lista `projects` al inicio de `script.js`.
- **Colores, tipografía y redondeo de esquinas:** variables en `:root`, al inicio de `styles.css`.
- **Imágenes y videos:** en `assets/`, una carpeta por proyecto (`Adela`, `Bless`, `Ruc`, `Key visual`).

## Publicar cambios

Cada cambio que se sube a la rama `main` (en VS Code: *Commit* → *Sync Changes*) se publica solo en Vercel.

## Archivos pesados

Los PDF, PSD, AI e INDD originales **no** van en este repositorio (están bloqueados en `.gitignore`).
Se guardan en el Escritorio, en la carpeta `portafolio_originales`.
Para la web se usan versiones livianas: imágenes `.webp` de máximo ~1600 px y videos `.mp4` comprimidos.
